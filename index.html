Streaming Multi-Speaker Voice Anonymization

Audio samples for the SMVA framework

Overview

SMVA processes incoming speech chunks, maintains speaker identity across turns, and assigns a stable pseudo-speaker within each conversation. This page presents paired source and anonymized audio using two generation backends: Qwen3-TTS and X-VC. The selected development examples contain two to five speakers.

Code availability: Inference code is being organized and reviewed. It is not public yet; we plan to release it if the paper is accepted.

Audio provenance and code

The 12 paired examples were recovered from a fixed 64-session MSA-clean development experiment. Source WAV files were converted to browser-compatible 16-kHz PCM without new inference or rescoring. The MSA authors’ examples above use different conversation IDs. These samples do not replace the full-set VPC2026 or official MSA evaluation.

Source conversations derive from the MSA benchmark and LibriSpeech. Please check upstream terms before reusing the audio. Inference code and model weights are undergoing release review and are not part of this public audio site.
